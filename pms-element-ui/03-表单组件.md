## 一、Form 表单

### 基础用法

```vue
<el-form :model="form" :rules="rules" ref="form" label-width="120px">
  <el-form-item label="用户名" prop="username">
    <el-input v-model="form.username"></el-input>
  </el-form-item>
  
  <el-form-item label="密码" prop="password">
    <el-input v-model="form.password" type="password"></el-input>
  </el-form-item>
  
  <el-form-item>
    <el-button type="primary" @click="submitForm">提交</el-button>
    <el-button @click="resetForm">重置</el-button>
  </el-form-item>
</el-form>

<script>
export default {
  data() {
    return {
      form: {
        username: '',
        password: ''
      },
      rules: {
        username: [
          { required: true, message: '请输入用户名', trigger: 'blur' }
        ],
        password: [
          { required: true, message: '请输入密码', trigger: 'blur' },
          { min: 6, message: '密码长度不能少于6位', trigger: 'blur' }
        ]
      }
    };
  },
  methods: {
    submitForm() {
      this.$refs.form.validate((valid) => {
        if (valid) {
          alert('submit!');
        }
      });
    },
    resetForm() {
      this.$refs.form.resetFields();
    }
  }
};
</script>
```

### 表单验证

**内置验证规则**：

- `required`: 必填
- `length`: 长度
- `min` / `max`: 最小/最大值
- `type`: 类型（email, url, number 等）
- `pattern`: 正则表达式
- `validator`: 自定义验证函数

```javascript
rules: {
  email: [
    { required: true, message: '请输入邮箱', trigger: 'blur' },
    { type: 'email', message: '请输入正确的邮箱格式', trigger: 'blur' }
  ],
  phone: [
    { required: true, message: '请输入手机号', trigger: 'blur' },
    { pattern: /^1[3-9]\d{9}$/, message: '请输入正确的手机号', trigger: 'blur' }
  ],
  password: [
    { required: true, message: '请输入密码', trigger: 'blur' },
    { validator: (rule, value, callback) => {
        if (value.length < 6) {
          callback(new Error('密码长度不能少于6位'));
        } else {
          callback();
        }
      }, trigger: 'blur' }
  ]
}
```

### 表单方法

| 方法 | 说明 |
|-----|------|
| validate | 整个表单验证 |
| validateField | 部分字段验证 |
| resetFields | 重置表单 |
| clearValidate | 清除验证 |

## 二、Input 输入框

### 基础用法

```vue
<el-input v-model="input" placeholder="请输入内容"></el-input>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| type | 类型 | string | text |
| maxlength | 最大长度 | number | - |
| minlength | 最小长度 | number | - |
| show-word-limit | 显示字数统计 | boolean | false |
| placeholder | 占位文本 | string | - |
| clearable | 可清空 | boolean | false |
| show-password | 显示密码切换 | boolean | false |
| trim | 是否自动清除输入值空格，`true` 等同于 `both` | boolean / string | true, both, start, end, left, right | false |
| disabled | 禁用 | boolean | false |
| prefix-icon | 头部图标 | string | - |
| suffix-icon | 尾部图标 | string | - |

### 文本域

```vue
<el-input
  type="textarea"
  :rows="2"
  placeholder="请输入内容"
  v-model="textarea"
  :autosize="{ minRows: 2, maxRows: 4 }"
>
</el-input>
```

### 复合型输入框

```vue
<el-input placeholder="请输入内容" v-model="input">
  <template slot="prepend">Http://</template>
</el-input>

<el-input placeholder="请输入内容" v-model="input">
  <template slot="append">.com</template>
</el-input>
```

### 自动清除空格

**功能说明**：使用 `trim` 属性可以在输入时自动清除空格。

- `trim` 或 `trim="both"`：清除前后空格
- `trim="start"` / `trim="left"`：只清除前面空格
- `trim="end"` / `trim="right"`：只清除后面空格

```vue
<el-input v-model="value" trim placeholder="自动清除前后空格" />
<el-input v-model="value" trim="start" placeholder="只清除前面空格" />
<el-input v-model="value" trim="end" placeholder="只清除后面空格" />
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |

| clearable | 可清空 | boolean | false |
| filterable | 可搜索 | boolean | false |
| collapse-tags | 折叠标签 | boolean | false |

### 多选

```vue

  <el-option label="选项一" value="1"></el-option>
  <el-option label="选项二" value="2"></el-option>
</el-select>
```

### 分组

```vue
<el-select v-model="value" placeholder="请选择">
  <el-option-group
    v-for="group in options"
    :key="group.label"
    :label="group.label">
    <el-option
      v-for="item in group.options"
      :key="item.value"
      :label="item.label"
      :value="item.value">
    </el-option>
  </el-option-group>
</el-select>
```

## 八、InputNumber 计数器

**功能说明**：仅允许在定义的范围内输入标准数值。

### 基础用法

```vue
<el-input-number v-model="num" @change="handleChange" :min="1" :max="10" label="描述文字"></el-input-number>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| value / v-model | 绑定值 | number | 0 |
| min | 最小值 | number | -Infinity |
| max | 最大值 | number | Infinity |
| step | 步长 | number | 1 |
| step-strictly | 是否只能输入 step 的倍数 | boolean | false |
| precision | 数值精度（必须为非负整数，且不小于 step 小数位） | number | — |
| size | 组件尺寸 | large / small | — |
| disabled | 是否禁用 | boolean | false |
| controls | 是否显示控制按钮 | boolean | true |
| controls-position | 控制按钮位置 | right | — |

### 常用事件

| 事件名 | 说明 | 参数 |
|-------|------|------|
| change | 绑定值变化时触发 | (currentValue, oldValue) |
| blur | 输入框失去焦点 | (event) |
| focus | 输入框获得焦点 | (event) |

### 注意事项

- `precision` 必须为非负整数，且不能小于 `step` 的小数位数
- 未设置 `min` 和 `max` 时，最小值默认为 0

## 十二、TimePicker 时间选择器

**功能说明**：允许选择或输入时间值。分为 TimeSelect（固定时间点）和 TimePicker（任意时间点）两个组件。

### 基础用法

```vue
<!-- 固定时间点 -->
<el-time-select v-model="value" :picker-options="{ start: '08:30', step: '00:15', end: '18:30' }" placeholder="选择时间"></el-time-select>

<!-- 任意时间点 -->
<el-time-picker v-model="value1" :picker-options="{ selectableRange: '18:30:00 - 20:30:00' }" placeholder="任意时间点"></el-time-picker>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| value / v-model | 绑定值 | Date (TimePicker) / string (TimeSelect) | — |
| readonly | 完全只读 | boolean | false |
| disabled | 禁用 | boolean | false |
| editable | 文本框可输入 | boolean | true |
| clearable | 显示清除按钮 | boolean | true |
| size | 输入框尺寸 | medium / small / mini | — |
| is-range | 是否为时间范围选择器（仅 TimePicker） | boolean | false |
| arrow-control | 使用箭头选择（仅 TimePicker） | boolean | false |
| picker-options | 当前组件特有的配置 | object | `{}` |
| value-format | 绑定值格式（仅 TimePicker），不设置则为 Date 对象 | string | — |

### picker-options 配置

**TimeSelect**：`start`（默认 '09:00'）、`end`（默认 '18:00'）、`step`（默认 '00:30'）、`minTime`、`maxTime`

**TimePicker**：`selectableRange`（字符串或字符串数组）、`format`（默认 'HH:mm:ss'）

### 常用事件

| 事件名 | 说明 | 参数 |
|-------|------|------|
| change | 值变化时触发 | — |
| blur | 失去焦点 | — |
| focus | 获得焦点 | — |

### 注意事项

- TimeSelect 和 TimePicker 是两个不同的组件（`el-time-select` vs `el-time-picker`）
- `is-range` 和 `arrow-control` 仅适用于 `el-time-picker`
- 时间范围选择时，绑定值为两个 Date 对象的数组

|-------|------|------|

## 十四、Rate 评分

### 基础用法

```vue
<el-rate v-model="value1"></el-rate>
<el-rate v-model="value2" :colors="colors"></el-rate>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| value / v-model | 绑定值 | number | 0 |
| max | 最大分值 | number | 5 |
| disabled | 只读模式（支持半星显示） | boolean | false |
| allow-half | 允许半选 | boolean | false |
| low-threshold / high-threshold | 分层阈值 | number | 2 / 4 |
| colors | 三个层级的颜色（数组或对象） | array / object | ['#F7BA2A', '#F7BA2A', '#F7BA2A'] |
| icon-classes | 三个层级的图标类名 | array / object | star-on 图标 |
| void-icon-class | 未选中图标类名 | string | el-icon-star-off |
| show-text | 显示辅助文字 | boolean | false |
| show-score | 显示当前分数 | boolean | false |
| texts | 辅助文字数组（长度应等于 max） | array | ['极差', '失望', '一般', '满意', '惊喜'] |
| score-template | 分数显示模板（含 `{value}`） | string | {value} |

### 常用事件

| 事件名 | 说明 | 参数 |
|-------|------|------|
| change | 分值变化时触发 | 新值 |

### 注意事项

- `show-text` 和 `show-score` 不能同时为 true
- 只读模式下支持小数分值显示

## 十五、Slider 滑块

**功能说明**：通过拖动滑块在一个固定区间内选择值。

### 基础用法

```vue
<el-slider v-model="value1"></el-slider>
<el-slider v-model="value" range show-stops :max="10"></el-slider>
<el-slider v-model="value" vertical height="200px"></el-slider>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| value / v-model | 绑定值（number 或范围时 array） | number / array | 0 |
| min | 最小值 | number | 0 |
| max | 最大值 | number | 100 |
| step | 步长 | number | 1 |
| disabled | 是否禁用 | boolean | false |
| show-input | 显示输入框（非 range 模式） | boolean | false |
| show-stops | 显示间断点 | boolean | false |
| show-tooltip | 显示 tooltip | boolean | true |
| format-tooltip | 格式化 tooltip | function(value) | — |
| range | 是否为范围选择 | boolean | false |
| vertical | 垂直模式 | boolean | false |
| height | 垂直模式高度（必填） | string | — |
| marks | 标记，key 必须在 [min, max] 内 | object | — |
| debounce | 输入框去抖延迟（ms） | number | 300 |

### 常用事件

|-------|------|------|

| input | 数据变化（拖动时实时触发） | 新值 |

### 注意事项

- `range` 为 true 时绑定值必须是数组 `[min, max]`

- `change` 在松开鼠标时触发，`input` 在拖动过程中连续触发

## 十七、Transfer 穿梭框

**功能说明**：双面板组件，用于在源列表和目标列表之间移动数据项。

### 基础用法

```vue
<el-transfer v-model="value" :data="data"></el-transfer>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| value / v-model | 绑定值（右侧面板 key 数组） | array | — |
| data | 数据源，每项需含 `{ key, label, disabled }` | array | `[]` |
| filterable | 是否可搜索 | boolean | false |
| filter-placeholder | 搜索框占位符 | string | 请输入搜索内容 |
| filter-method | 自定义过滤函数 | function(query, item) | — |
| target-order | 右侧列表排序策略 | original / push / unshift | original |
| titles | 面板标题 | array | ['列表 1', '列表 2'] |
| button-texts | 按钮文案 | array | `[]` |
| render-content | 自定义渲染函数（JSX） | function(h, option) | — |
| format | 勾选状态文案格式 `{ noChecked, hasChecked }` | object | `${checked}/${total}` |
| props | 字段别名映射 `{ key, label, disabled }` | object | — |
| left-default-checked / right-default-checked | 初始勾选的 key | array | `[]` |

### 插槽

| 插槽名 | 说明 |
|-------|------|
| left-footer / right-footer | 各面板底部内容 |
| `{ option }` | 自定义选项渲染（scoped slot） |

### 常用事件

| 事件名 | 说明 | 参数 |
|-------|------|------|
| change | 右侧列表变化 | (value, direction, movedKeys) |
| left-check-change | 左侧勾选变化 | (checkedKeys, changedKeys) |
| right-check-change | 右侧勾选变化 | (checkedKeys, changedKeys) |
| load | 滚动到底部触发（无限加载） | — |

### 方法

| 方法名 | 说明 | 参数 |
|-------|------|------|
| clearQuery | 清除指定面板搜索关键词 | 'left' / 'right' |

### 注意事项

- `data` 数组每项必须有 `key` 字段，可用 `props` 别名映射
- `render-content` 使用 JSX（`h` 函数），不支持 JSX 的环境请用 scoped slot 替代
- `format` 使用 `${checked}` 和 `${total}` 占位符
