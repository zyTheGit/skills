## 组件列表

| 组件 | 说明 | 常用场景 |
|-----|------|---------|
| Button | 按钮 | 按钮操作 |
| Link | 链接 | 文字链接 |
| Icon | 图标 | 图标组件 |

## 一、Button 按钮

### 基础用法

```vue
<el-row>
  <el-button>默认按钮</el-button>
  <el-button type="primary">主要按钮</el-button>
  <el-button type="success">成功按钮</el-button>
  <el-button type="info">信息按钮</el-button>
  <el-button type="warning">警告按钮</el-button>
  <el-button type="danger">危险按钮</el-button>
</el-row>
```

### 按钮样式

```vue
<!-- 朴素按钮 -->
<el-button type="primary" plain>朴素按钮</el-button>

<!-- 圆角按钮 -->
<el-button type="primary" round>圆角按钮</el-button>

<!-- 图标按钮 -->
<el-button type="primary" icon="el-icon-search" circle></el-button>

<!-- 加载中 -->
<el-button type="primary" :loading="loading">加载中</el-button>
```

### 按钮尺寸

```vue
<el-button size="medium">中等按钮</el-button>
<el-button size="small">小型按钮</el-button>
<el-button size="mini">超小按钮</el-button>
```

### 按钮组

```vue
<el-button-group>
  <el-button type="primary" icon="el-icon-arrow-left">上一页</el-button>
  <el-button type="primary">下一页<i class="el-icon-arrow-right el-icon--right"></i></el-button>
</el-button-group>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| type | 类型 | string | default |
| size | 尺寸 | string | - |
| icon | 图标类名 | string | - |
| plain | 朴素按钮 | boolean | false |
| round | 圆角按钮 | boolean | false |
| circle | 圆形按钮 | boolean | false |
| loading | 加载中 | boolean | false |
| disabled | 禁用 | boolean | false |

## 四、InfiniteScroll 无限滚动

### 基础用法

```vue
<ul class="infinite-list" v-infinite-scroll="load" infinite-scroll-disabled="disabled">
  <li v-for="i in count" :key="i" class="infinite-list-item">{{ i }}</li>
</ul>

<script>
export default {
  data() {
    return {
      count: 10
    };
  },
  methods: {
    load() {
      this.count += 2;
    }
  }
};
</script>
```

## 五、常用组合示例

### 工具栏按钮组

```vue
<el-row type="flex" justify="space-between" align="middle">
  <el-col>
    <el-button type="primary" icon="el-icon-plus" @click="handleAdd">新增</el-button>
    <el-button type="danger" icon="el-icon-delete" @click="handleBatchDelete">批量删除</el-button>
    <el-button icon="el-icon-download" @click="handleExport">导出</el-button>
  </el-col>
  <el-col style="text-align: right;">
    <el-button icon="el-icon-refresh" @click="handleRefresh">刷新</el-button>
  </el-col>
</el-row>
```

### 操作列按钮

```vue
<el-table-column label="操作" width="200">
  <template slot-scope="scope">
    <el-link type="primary" icon="el-icon-edit" @click="handleEdit(scope.row)">编辑</el-link>
    <el-divider direction="vertical"></el-divider>
    <el-link type="primary" icon="el-icon-view" @click="handleView(scope.row)">查看</el-link>
    <el-divider direction="vertical"></el-divider>
    <el-popconfirm title="确定删除吗？" @confirm="handleDelete(scope.row.id)">
      <el-link slot="reference" type="danger" icon="el-icon-delete">删除</el-link>
    </el-popconfirm>
  </template>
</el-table-column>
```

### 详情页操作栏

```vue
<el-page-header @back="goBack" :content="title">
  <template slot="content">
    <span>{{ title }}</span>
    <el-tag size="small" :type="statusType">{{ statusText }}</el-tag>
  </template>
  <template slot="extra">
    <el-button type="primary" @click="handleEdit">编辑</el-button>
    <el-button @click="handlePrint">打印</el-button>
    <el-button type="danger" @click="handleDelete">删除</el-button>
  </template>
</el-page-header>
```
