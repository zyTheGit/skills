## 一、Table 表格

### 基础用法

```vue
<el-table :data="tableData" style="width: 100%">
  <el-table-column prop="date" label="日期" width="180"></el-table-column>
  <el-table-column prop="name" label="姓名" width="180"></el-table-column>
  <el-table-column prop="address" label="地址"></el-table-column>
</el-table>

<script>
export default {
  data() {
    return {
      tableData: [
        {
          date: '2024-05-02',
          name: '王小虎',
          address: '上海市普陀区金沙江路 1518 弄'
        }
      ]
    };
  }
};
</script>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| data | 数据源 | array | - |
| height | 高度 | string / number | - |
| max-height | 最大高度 | string / number | - |
| stripe | 斑马纹 | boolean | false |
| border | 边框 | boolean | false |
| row-key | 行标识 | string / function | - |
| show-header | 显示表头 | boolean | true |

### 排序

```vue
<el-table :data="tableData" @sort-change="handleSortChange">
  <el-table-column prop="date" label="日期" sortable="custom"></el-table-column>
  <el-table-column prop="name" label="姓名"></el-table-column>
</el-table>
```

### 筛选

```vue
<el-table :data="tableData">
  <el-table-column
    prop="tag"
    label="标签"
    :filters="[{ text: '家', value: '家' }, { text: '公司', value: '公司' }]"
    :filter-method="filterTag">
  </el-table-column>
</el-table>
```

### 自定义列模板

```vue
<el-table :data="tableData">
  <el-table-column prop="date" label="日期">
    <template slot-scope="scope">
      <i class="el-icon-time"></i>
      <span style="margin-left: 10px">{{ scope.row.date }}</span>
    </template>
  </el-table-column>
  <el-table-column label="操作">
    <template slot-scope="scope">
      <el-button size="mini" @click="handleEdit(scope.$index, scope.row)">编辑</el-button>
      <el-button size="mini" type="danger" @click="handleDelete(scope.$index, scope.row)">删除</el-button>
    </template>
  </el-table-column>
</el-table>
```

## 九、Calendar 日历

### el-calendar 基础用法

```vue
<el-calendar v-model="value">
</el-calendar>

<script>
export default {
  data() {
    return {
      value: new Date()
    }
  }
}
</script>
```

### el-calendar 自定义内容

```vue
<el-calendar>
  <template slot="dateCell" slot-scope="{date, data}">
    <p :class="data.isSelected ? 'is-selected' : ''">
      {{ data.day.split('-').slice(1).join('-') }}
    </p>
  </template>
</el-calendar>
```

### el-calendar Attributes

| 参数 | 说明 | 类型 | 默认值 |
| ----- | ------ | ----- | ------ |
| value / v-model | 绑定值 | Date/string/number | — |
| range | 时间范围，开始时间必须是周一，结束时间必须是周日，跨度不超过两个月 | Array | — |
| first-day-of-week | 周起始日 | Number (1-7) | 1 |

### el-calendar-new 新日历

```vue
<el-calendar-new
  v-model="value"
  :first-day-of-week="7"
  :day-need-border="false"
  :keep-one-day="true"
  :show-footer="true"
  :picker-options="pickerOptions"
/>
```

### el-calendar-new Attributes

| 参数 | 说明 | 类型 | 默认值 |
| ----- | ------ | ----- | ------ |
| value / v-model | 绑定值 | Date/string/number | — |
| first-day-of-week | 周起始日 | Number (1-7) | 1 |
| day-need-border | 是否显示日期边框 | Boolean | true |
| keep-one-day | 切换年月时是否只显示当前日期 | Boolean | true |
| show-footer | 是否显示底部操作按钮 | Boolean | true |
| picker-options | 日期禁用配置 | Object | — |

### dateCell scoped slot 参数

| 参数 | 说明 | 类型 |
| ---- | ------ | ----- |
| date | 单元格代表的日期 | Date |
| data | `{ type, isSelected, day }`，type 可选值：prev-month, current-month, next-month, next-year, prev-year | Object |

## 十一、Image 图片

**功能说明**：图片容器，支持懒加载、自定义占位符和加载失败容错，保留原生 img 行为。

### 基础用法

```vue
<el-image
  style="width: 100px; height: 100px"
  :src="url"
  :preview-src-list="srcList"
  fit="cover">
</el-image>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| src | 图片源 URL | string | — |
| fit | 填充模式（同 CSS object-fit） | fill / contain / cover / none / scale-down | — |
| lazy | 是否懒加载 | boolean | false |
| scroll-container | 懒加载的滚动容器 | string / HTMLElement | 最近的 overflow auto/scroll 父元素 |
| preview-src-list | 开启预览，提供图片 URL 数组 | array | — |
| z-index | 预览遮罩层 z-index | number | 2000 |
| initial-index | 初始预览图片索引 | number | — |

### 常用事件

| 事件名 | 说明 | 参数 |
|-------|------|------|
| load | 图片加载成功 | — |
| error | 图片加载失败 | — |

### 插槽

| 插槽名 | 说明 |
|-------|------|
| placeholder | 加载中占位内容 |
| error | 加载失败容错内容 |

### 注意事项

- 使用 `preview-src-list` 时，点击图片会打开全屏预览遮罩

| type | 类型（card 为卡片模式） | string | — |

| 事件名 | 说明 | 参数 |

## 十七、Skeleton 骨架屏

**功能说明**：内容加载时显示的占位预览，某些场景下比旋转动画更直观。

### 基础用法

```vue
<el-skeleton :rows="6" :loading="loading" animated>
  <template slot="template">
    <el-skeleton-item variant="image" style="width: 240px; height: 240px;" />
    <el-skeleton-item variant="h3" style="width: 50%;" />
  </template>
  <template>
    <!-- loading=false 时显示真实 UI -->
    <el-card>...</el-card>
  </template>
</el-skeleton>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| animated | 是否开启动画 | boolean | false |
| count | 模板重复次数 | number | 1 |
| loading | 是否显示骨架屏 | boolean | true |
| rows | 段落行数 | number | 4 |
| throttle | 渲染占位 DOM 前的延迟（ms） | number | 0 |

### Skeleton Item 属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| variant | 显示形状 | p / h1 / h3 / text / caption / button / image / circle / rect | text |

### 注意事项

- `count` 不宜过大，避免性能问题
- `throttle` 可防止 API 响应过快时的闪烁

## 十八、Tree 树形控件

**功能说明**：以树形结构展示层级数据，支持展开/折叠节点。

### 基础用法

```vue
<el-tree
  :data="data"
  show-checkbox
  node-key="id"
  :props="defaultProps"
  @node-click="handleNodeClick">
</el-tree>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| data | 树形数据 | array | — |
| node-key | 节点唯一标识字段（基于 key 的方法必填） | string | — |
| props | 配置项 `{ children, label, disabled, isLeaf }` | object | — |
| show-checkbox | 显示复选框 | boolean | false |
| check-strictly | 父子节点复选框独立 | boolean | false |
| default-expand-all | 默认展开所有节点 | boolean | false |
| accordion | 同级只展开一个 | boolean | false |
| lazy | 懒加载子节点（配合 `load`） | boolean | false |
| load | 懒加载处理函数 | function(node, resolve) | — |
| draggable | 是否可拖拽 | boolean | false |
| filter-node-method | 自定义过滤函数 | function | — |
| render-content | 自定义渲染函数（JSX） | function(h, {node, data, store}) | — |

### 常用事件

| 事件名 | 说明 | 参数 |
|-------|------|------|
| node-click | 节点点击 | (data, node, component) |
| check-change | 复选框变化 | (data, checked, indeterminate) |
| check | 复选框点击 | (data, { checkedKeys, checkedNodes }) |
| current-change | 当前选中节点变化 | (data, node) |
| node-expand | 节点展开 | (data, node, component) |
| node-collapse | 节点折叠 | (data, node, component) |
| node-drag-start | 开始拖拽 | — |
| node-drag-end | 拖拽完成 | — |
| node-drop | 拖拽放下 | — |

### 方法

| 方法名 | 说明 | 参数 |
|-------|------|------|
| filter | 过滤节点 | (value) |
| getCheckedNodes | 获取选中节点 | (leafOnly) |
| setCheckedNodes | 设置选中节点 | (nodes) |
| getCheckedKeys | 获取选中 key | (leafOnly) |
| setCheckedKeys | 设置选中 key | (keys) |
| getNode | 获取节点 | (key/data) |
| expandNode / collapseNode | 展开/折叠节点 | (key) |
| expandAll / collapseAll | 展开/折叠所有 | — |
| append / remove | 添加/删除节点 | — |
| insertBefore / insertAfter | 前插/后插节点 | — |

### 注意事项

- 懒加载场景下 `expandAll` 会递归加载并返回 Promise，需使用 `await`
- 自定义内容通过 `render-content`（JSX）或 scoped slot（`slot-scope="{ node, data }"`）实现
