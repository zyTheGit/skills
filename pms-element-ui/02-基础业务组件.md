## 一、BaseProTable 高级表格

### 核心特性

- 通过 `columns` 配置自动渲染搜索栏和表格列
- 集成搜索、分页、工具栏、列设置、**数据请求**
- 支持多种 `valueType` 展示类型
- 自动数据请求（推荐）

### 基础用法

```vue
<template>
  <el-base-pro-table
    :columns="columns"
    :request="fetchData"
    show-index
    show-single-selection
    @request-success="onSuccess"
  />
</template>

<script>
export default {
  data() {
    return {
      columns: [
        { title: '编号', dataIndex: 'code', search: true, width: 120 },
        { title: '名称', dataIndex: 'name', search: true, width: 160 },
        {
          title: '状态',
          dataIndex: 'status',
          width: 120,
          valueType: 'tag',
          valueEnum: {
            1: { text: '正常', status: 'success' },
            2: { text: '异常', status: 'danger' }
          },
          search: {
            type: 'Select',
            options: [
              { label: '全部', value: '' },
              { label: '正常', value: 1 },
              { label: '异常', value: 2 }
            ]
          }
        },
        {
          title: '创建时间',
          dataIndex: 'createTime',
          width: 180,
          sortable: 'custom'
        }
      ]
    };
  },
  methods: {
    fetchData(params) {
      // params 自动包含分页、搜索、排序参数
      return new Promise(resolve => {
        setTimeout(() => {
          const { page = 1, pageSize = 10 } = params;
          resolve({
            data: [], // 数据数组
            total: 100, // 总数
            success: true
          });
        }, 500);
      });
    }
  }
};
</script>
```

### valueEnum 值枚举

支持简写格式和完整格式：

```javascript
// 简写格式
valueEnum: {
  1: '启用',
  0: '禁用'
}

// 完整格式
valueEnum: {
  1: { text: '启用', status: 'success' },
  0: { text: '禁用', status: 'danger' }
}

// 自定义颜色
valueEnum: {
  1: { text: '启用', color: '#67C23A' },
  0: { text: '禁用', color: '#909399' }
}
```

### valueDict 字典映射（异步）

使用字典数据自动加载并缓存：

```javascript
// 方式1：使用默认字典接口
{
  title: '性别',
  dataIndex: 'sex',
  valueDict: {
    appCode: 'upms',
    distTypeCode: 'user_info_sex'
  }
}

// 方式2：使用自定义请求函数
{
  title: '所属部门',
  dataIndex: 'deptId',
  valueDict: {
    request: async () => {
      const res = await fetch('/api/dept/list').then(r => r.json())
      return res.data
    },
    distItemProps: { label: 'name', value: 'id' },
    cacheKey: 'dept_list'
  }
}
```

**优先级说明**：`valueDict` > `valueEnum` > `formatter`

### 列宽规则

组件内置智能列宽规则：

1. **少列情况**（<4列）：每列单行字数建议 30-35 字
2. **多列情况**（≥4列）：每列单行字数建议 20-25 字
3. **文字最多占两行**，超出用"..."+"文字提示"
4. **响应式适配**：小屏（如 1366x768）自动缩减列宽至 15-20 字
5. **金额右对齐，千分位**
6. **不建议换行**：操作列、状态/类型/编码、数值/日期/时间
7. **建议换行**：长单位名称、备注/描述类长文本

### 在弹框中使用

```vue

      :columns="columns"
      :show-toolbar="false"
      :data="tableData"
      :is-in-dialog="true"
    />
  </div>
</el-dialog>
```

## 二、BaseProForm 高级表单

### 核心特性

- 支持查看（view）、新增（add）、编辑（edit）三种模式
- 与 BaseProTable 共享 columns 配置
- 内置抽屉容器
- 支持分组展示、字段脱敏、自定义渲染

### 默认布局

- **抽屉模式**：默认一行显示一个表单字段（span=24）
- **内联模式**：默认一行最多显示三个表单字段（span=8）

### 基础用法

```vue
<template>
  <el-base-pro-form
    :visible.sync="visible"
    :mode="mode"
    :columns="columns"
    :initial-values="formData"
    @submit="handleSubmit"
    @cancel="handleCancel"
  />
</template>

<script>
export default {
  data() {
    return {
      visible: false,
      mode: 'add', // 'add' | 'edit' | 'view'
      columns: [
        {
          title: '用户名',
          dataIndex: 'username',
          form: {
            type: 'Input',
            rules: [{ required: true, message: '请输入用户名' }]
          }
        },
        {
          title: '邮箱',
          dataIndex: 'email',
          form: {
            type: 'Input',
            rules: [
              { required: true, message: '请输入邮箱' },
              { type: 'email', message: '请输入正确的邮箱格式' }
            ]
          }
        },
        {
          title: '性别',
          dataIndex: 'gender',
          form: {
            type: 'Radio',
            options: [
              { label: '男', value: 'male' },
              { label: '女', value: 'female' }
            ]
          },
          valueEnum: {
            male: '男',
            female: '女'
          }
        }
      ],
      formData: {
        username: 'admin',
        email: 'admin@example.com',
        gender: 'male'
      }
    };
  },
  methods: {
    handleSubmit(data, mode) {
      console.log('提交数据:', data, '模式:', mode);
      this.visible = false;
    },
    handleCancel() {
      this.visible = false;
    }
  }
};
</script>
```

### 字段联动

**优先使用 `form.show`** 控制字段显隐：
- 仅控制字段显示/隐藏时使用

**使用 `form.linkage`** 处理复杂联动：
- 需要清空其他字段
- 需要动态加载选项
- 需要回填值或执行异步逻辑

```javascript
columns: [
  {
    title: '用户类型',
    dataIndex: 'userType',
    form: {
      type: 'Radio',
      options: [
        { label: '个人用户', value: 'personal' },
        { label: '企业用户', value: 'company' }
      ]
    }
  },
  {
    title: '姓名',
    dataIndex: 'name',
    form: {
      type: 'Input',
      show: (model) => model.userType === 'personal'
    }
  },
  {
    title: '公司名称',
    dataIndex: 'companyName',
    form: {
      type: 'Input',
      show: (model) => model.userType === 'company'
    }
  },
  {
    title: '省份',
    dataIndex: 'province',
    form: {
      type: 'Select',
      options: [
        { label: '北京', value: 'beijing' },
        { label: '上海', value: 'shanghai' }
      ],
      linkage: {
        set: () => ({ city: undefined }),
        clearOptions: 'cityOptions',
        fetch: (value) => {
          return this.fetchCities(value);
        },
        optionsKey: 'cityOptions'
      }
    }
  }
]
```

```vue

<!-- 内联模式 -->
```

### 查看模式（内联）

使用 `el-descriptions` 组件实现 label-value 左右布局：

```vue
<el-base-pro-form
  :drawer="false"
  mode="view"
  :isInline="true"
  :columns="columns"
  :initial-values="formData"
  :view-column="3"
  :view-responsive="true"
  :view-border="true"
/>
```

**查看模式规则**：
1. `view-column` 表示期望列数上限（1-3）
2. `view-responsive=true` 时按容器宽度自适应
3. 标签列默认固定宽度 `164px`
4. 多列场景最小宽度为 `533px`
5. 标签默认最多显示 2 行
6. 使用 `form.viewSpan` 配置跨列

### 搜索项联动

```javascript
columns: [
  {
    title: '省份',
    dataIndex: 'province',
    search: {
      type: 'Select',
      options: [
        { label: '广东省', value: 'gd' },
        { label: '浙江省', value: 'zj' }
      ],
      linkage: [
        {
          reset: ['city', 'district'],
          optionsKey: 'cityOptions',
          fetch: (value) => {
            const cityMap = {
              gd: [{ label: '广州', value: 'gz' }, { label: '深圳', value: 'sz' }],

            return Promise.resolve(cityMap[value] || []);
          }
        }
      ]
    }
  },
  {
    title: '城市',
    dataIndex: 'city',
    search: {
      type: 'Select',
      optionsKey: 'cityOptions',
      disabled: (model) => !model.province
    }
  }
]
```

## 四、BaseToolBar 工具栏

### 核心特性

- 从 `BaseProTable` 中提取的独立工具栏组件
- 支持刷新、密度切换、列设置、全屏切换
- 可独立嵌入业务列表头部、卡片区右上角

### 基础用法

```vue
<template>
  <el-base-tool-bar
    :show-refresh="true"
    :show-density="true"
    :show-fullscreen="true"
    :show-column-setting="false"
    :density="density"
    :is-fullscreen="isFullscreen"
    @refresh="handleRefresh"
    @density-change="handleDensityChange"
    @fullscreen-toggle="handleFullscreenToggle"
  />
</template>

<script>
export default {
  data() {
    return {
      density: 'default',
      isFullscreen: false
    };
  },
  methods: {
    handleRefresh() {
      this.$message.success('触发刷新');
    },
    handleDensityChange(value) {
      this.density = value;
    },
    handleFullscreenToggle() {
      this.isFullscreen = !this.isFullscreen;
    }
  }
};
</script>
```

### 列设置功能

```vue
<el-base-tool-bar
  :show-column-setting="true"
  :columns="columns"
  :column-state="columnState"
  @column-setting-confirm="handleColumnSettingConfirm"
/>

<script>
export default {
  data() {
    return {
      columns: [
        { title: '姓名', dataIndex: 'name' },
        { title: '部门', dataIndex: 'dept' },
        { title: '状态', dataIndex: 'status', fixed: 'right' }
      ],
      columnState: {
        name: { visible: true, order: 0 },
        dept: { visible: true, order: 1 },
        status: { visible: true, order: 2 }
      }
    };
  },
  methods: {
    handleColumnSettingConfirm({ state }) {
      this.columnState = state;
    }
  }
};
</script>
```

### 与列表头部组合使用

```vue
<div style="display: flex; align-items: center; justify-content: space-between;">
  <div>
    <div style="font-size: 16px; font-weight: 500;">项目列表</div>

    :show-column-setting="false"

    @density-change="density = $event"
  />

```

### Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
|-----|------|------|--------|--------|
| showRefresh | 是否显示刷新按钮 | boolean | — | true |
| showDensity | 是否显示密度切换 | boolean | — | true |
| showColumnSetting | 是否显示列设置 | boolean | — | true |
| showFullscreen | 是否显示全屏切换 | boolean | — | true |
| density | 当前表格密度 | string | default / medium / small / mini | default |
| isFullscreen | 当前是否全屏 | boolean | — | false |
| columns | 列设置使用的列配置 | array | — | [] |
| columnState | 列设置使用的列状态 | object | — | {} |

### Events

| 事件名 | 说明 | 回调参数 |
|-------|------|---------|
| refresh | 点击刷新按钮时触发 | — |
| density-change | 切换密度时触发 | density: string |
| fullscreen-toggle | 点击全屏切换时触发 | — |
| column-setting-confirm | 列设置确认时触发 | { state, config } |

## 七、常见问题

### 1. BaseProTable 不显示数据？

检查：
- 是否正确配置了 `request` 函数
- `request` 函数是否返回 `{ data: [], total: 0, success: true }` 格式
- 是否设置了 `:data` 属性（与 `request` 二选一）

### 2. BaseProForm 提交数据不正确？

检查：
- 是否正确设置了 `:initial-values`（编辑模式）
- 字段的 `dataIndex` 是否与数据字段名一致
- 是否正确配置了 `form.type`

### 3. BaseDictionary 不显示选项？

检查：
- 是否正确配置了 `appCode` 和 `distTypeCode`
- 字典数据是否已配置
- 网络请求是否正常

### 4. 文件上传失败？

检查：
- 是否正确配置了 `action` 地址
- 是否设置了 `autoUpload` 或手动调用上传
- 文件大小是否超过 `maxFileSize` 限制
- 文件类型是否符合 `accept` 要求
