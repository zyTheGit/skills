## 一、BaseProTable 高级表格

### 核心特性

- 通过 `columns` 配置自动渲染搜索栏和表格列
- 集成搜索、分页、工具栏、列设置、**数据请求**
- 支持多种 `valueType` 展示类型
- 自动数据请求（推荐）

### 基础用法

```vue
<template>
  <el-base-pro-table
    :columns="columns"
    :request="fetchData"
    show-index
    show-single-selection
    @request-success="onSuccess"
  />
</template>

<script>
export default {
  data() {
    return {
      columns: [
        { title: '编号', dataIndex: 'code', search: true, width: 120 },
        { title: '名称', dataIndex: 'name', search: true, width: 160 },
        {
          title: '状态',
          dataIndex: 'status',
          width: 120,
          valueType: 'tag',
          valueEnum: {
            1: { text: '正常', status: 'success' },
            2: { text: '异常', status: 'danger' }
          },
          search: {
            type: 'Select',
            options: [
              { label: '全部', value: '' },
              { label: '正常', value: 1 },
              { label: '异常', value: 2 }
            ]
          }
        },
        {
          title: '创建时间',
          dataIndex: 'createTime',
          width: 180,
          sortable: 'custom'
        }
      ]
    };
  },
  methods: {
    fetchData(params) {
      // params 自动包含分页、搜索、排序参数
      return new Promise(resolve => {
        setTimeout(() => {
          const { page = 1, pageSize = 10 } = params;
          resolve({
            data: [], // 数据数组
            total: 100, // 总数
            success: true
          });
        }, 500);
      });
    }
  }
};
</script>
```

### valueEnum 值枚举

支持简写格式和完整格式：

```javascript
// 简写格式
valueEnum: {
  1: '启用',
  0: '禁用'
}

// 完整格式
valueEnum: {
  1: { text: '启用', status: 'success' },
  0: { text: '禁用', status: 'danger' }
}

// 自定义颜色
valueEnum: {
  1: { text: '启用', color: '#67C23A' },
  0: { text: '禁用', color: '#909399' }
}
```

### valueDict 字典映射（异步）

使用字典数据自动加载并缓存：

```javascript
// 方式1：使用默认字典接口
{
  title: '性别',
  dataIndex: 'sex',
  valueDict: {
    appCode: 'upms',
    distTypeCode: 'user_info_sex'
  }
}

// 方式2：使用自定义请求函数
{
  title: '所属部门',
  dataIndex: 'deptId',
  valueDict: {
    request: async () => {
      const res = await fetch('/api/dept/list').then(r => r.json())
      return res.data
    },
    distItemProps: { label: 'name', value: 'id' },
    cacheKey: 'dept_list'
  }
}
```

**优先级说明**：`valueDict` > `valueEnum` > `formatter`

### 列宽规则

组件内置智能列宽规则：

1. **少列情况**（<4列）：每列单行字数建议 30-35 字
2. **多列情况**（≥4列）：每列单行字数建议 20-25 字
3. **文字最多占两行**，超出用"..."+"文字提示"
4. **响应式适配**：小屏（如 1366x768）自动缩减列宽至 15-20 字
5. **金额右对齐，千分位**
6. **不建议换行**：操作列、状态/类型/编码、数值/日期/时间
7. **建议换行**：长单位名称、备注/描述类长文本

### 单项禁用控制

单选模式下，通过 `single-selectable` 控制哪些行不可选中：

```vue
<el-base-pro-table
  :columns="columns"
  :request="fetchData"
  show-single-selection
  :single-selectable="checkSingleSelectable"
  @single-selection-change="handleSingleSelectionChange"
/>

<script>
export default {
  methods: {
    checkSingleSelectable(row) {
      return row.status !== 2; // status=2 的行禁用选中
    }
  }
};
</script>
```

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| single-selectable | 单选框可选判断，返回 false 时该行单选禁用 | Function(row, index) | — |

## 二、BaseProForm 高级表单

### 核心特性

- 支持查看（view）、新增（add）、编辑（edit）三种模式
- 与 BaseProTable 共享 columns 配置
- 内置抽屉容器
- 支持分组展示、字段脱敏、自定义渲染

### 默认布局

- **抽屉模式**：默认一行显示一个表单字段（span=24）
- **内联模式**：默认一行最多显示三个表单字段（span=8）

### 基础用法

```vue
<template>
  <el-base-pro-form
    :visible.sync="visible"
    :mode="mode"
    :columns="columns"
    :initial-values="formData"
    @submit="handleSubmit"
    @cancel="handleCancel"
  />
</template>

<script>
export default {
  data() {
    return {
      visible: false,
      mode: 'add', // 'add' | 'edit' | 'view'
      columns: [
        {
          title: '用户名',
          dataIndex: 'username',
          form: {
            type: 'Input',
            rules: [{ required: true, message: '请输入用户名' }]
          }
        },
        {
          title: '邮箱',
          dataIndex: 'email',
          form: {
            type: 'Input',
            rules: [
              { required: true, message: '请输入邮箱' },
              { type: 'email', message: '请输入正确的邮箱格式' }
            ]
          }
        },
        {
          title: '性别',
          dataIndex: 'gender',
          form: {
            type: 'Radio',
            options: [
              { label: '男', value: 'male' },
              { label: '女', value: 'female' }
            ]
          },
          valueEnum: {
            male: '男',
            female: '女'
          }
        }
      ],
      formData: {
        username: 'admin',
        email: 'admin@example.com',
        gender: 'male'
      }
    };
  },
  methods: {
    handleSubmit(data, mode) {
      console.log('提交数据:', data, '模式:', mode);
      this.visible = false;
    },
    handleCancel() {
      this.visible = false;
    }
  }
};
</script>
```

### 字段联动

**优先使用 `form.show`** 控制字段显隐：
- 仅控制字段显示/隐藏时使用

**使用 `form.linkage`** 处理复杂联动：
- 需要清空其他字段
- 需要动态加载选项
- 需要回填值或执行异步逻辑

```javascript
columns: [
  {
    title: '用户类型',
    dataIndex: 'userType',
    form: {
      type: 'Radio',
      options: [
        { label: '个人用户', value: 'personal' },
        { label: '企业用户', value: 'company' }
      ]
    }
  },
  {
    title: '姓名',
    dataIndex: 'name',
    form: {
      type: 'Input',
      show: (model) => model.userType === 'personal'
    }
  },
  {
    title: '公司名称',
    dataIndex: 'companyName',
    form: {
      type: 'Input',
      show: (model) => model.userType === 'company'
    }
  },
  {
    title: '省份',
    dataIndex: 'province',
    form: {
      type: 'Select',
      options: [
        { label: '北京', value: 'beijing' },
        { label: '上海', value: 'shanghai' }
      ],
      linkage: {
        set: () => ({ city: undefined }),
        clearOptions: 'cityOptions',
        fetch: (value) => {
          return this.fetchCities(value);
        },
        optionsKey: 'cityOptions'
      }
    }
  }
]
```

```vue

  :visible.sync="drawerVisible"

  :columns="columns"

    :drawer="false"
```

### 查看模式（内联）

使用 `el-descriptions` 组件实现 label-value 左右布局：

```vue
<el-base-pro-form
  :drawer="false"
  mode="view"
  :isInline="true"
  :columns="columns"
  :initial-values="formData"
  :view-column="3"
  :view-responsive="true"
  :view-border="true"
/>
```

**查看模式规则**：
1. `view-column` 表示期望列数上限（1-3）
2. `view-responsive=true` 时按容器宽度自适应
3. 标签列默认固定宽度 `164px`
4. 多列场景最小宽度为 `533px`
5. 标签默认最多显示 2 行
6. 使用 `form.viewSpan` 配置跨列

## 三、BaseProSearch 高级搜索

### 核心特性

- 通过 `columns` 配置自动渲染搜索项
- 支持展开/收起、联动等功能
- 支持 PageHeader 标题

### 基础用法

```vue
<el-base-pro-search
  :columns="columns"
  :model.sync="searchForm"
  @search="handleSearch"
  @reset="handleReset"
/>
```

### PageHeader 标题

```vue
<el-base-pro-search
  show-page-header
  :page-header="{ title: '返回', content: '用户详情' }"
  :columns="columns"
  :model.sync="searchForm"
  @back="handleBack"
  @search="handleSearch"
/>
```

### 搜索项联动

```javascript
columns: [
  {
    title: '省份',
    dataIndex: 'province',
    search: {
      type: 'Select',
      options: [
        { label: '广东省', value: 'gd' },
        { label: '浙江省', value: 'zj' }
      ],
      linkage: [
        {
          reset: ['city', 'district'],
          optionsKey: 'cityOptions',
          fetch: (value) => {
            const cityMap = {
              gd: [{ label: '广州', value: 'gz' }, { label: '深圳', value: 'sz' }],
              zj: [{ label: '杭州', value: 'hz' }, { label: '宁波', value: 'nb' }]
            };
            return Promise.resolve(cityMap[value] || []);
          }
        }
      ]
    }
  },
  {
    title: '城市',
    dataIndex: 'city',
    search: {
      type: 'Select',
      optionsKey: 'cityOptions',
      disabled: (model) => !model.province
    }
  }
]
```

## 四、BaseToolBar 工具栏

### 核心特性

- 从 `BaseProTable` 中提取的独立工具栏组件
- 支持刷新、密度切换、列设置、全屏切换
- 可独立嵌入业务列表头部、卡片区右上角

### 基础用法

```vue
<template>
  <el-base-tool-bar
    :show-refresh="true"
    :show-density="true"
    :show-fullscreen="true"
    :show-column-setting="false"
    :density="density"
    :is-fullscreen="isFullscreen"
    @refresh="handleRefresh"
    @density-change="handleDensityChange"
    @fullscreen-toggle="handleFullscreenToggle"
  />
</template>

<script>
export default {
  data() {
    return {
      density: 'default',
      isFullscreen: false
    };
  },
  methods: {
    handleRefresh() {
      this.$message.success('触发刷新');
    },
    handleDensityChange(value) {
      this.density = value;
    },
    handleFullscreenToggle() {
      this.isFullscreen = !this.isFullscreen;
    }
  }
};
</script>
```

### 列设置功能

```vue
<el-base-tool-bar
  :show-column-setting="true"
  :columns="columns"
  :column-state="columnState"
  @column-setting-confirm="handleColumnSettingConfirm"
/>

<script>
export default {
  data() {
    return {
      columns: [
        { title: '姓名', dataIndex: 'name' },
        { title: '部门', dataIndex: 'dept' },
        { title: '状态', dataIndex: 'status', fixed: 'right' }
      ],
      columnState: {
        name: { visible: true, order: 0 },
        dept: { visible: true, order: 1 },
        status: { visible: true, order: 2 }
      }
    };
  },
  methods: {
    handleColumnSettingConfirm({ state }) {
      this.columnState = state;
    }
  }
};
</script>
```

### Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
|-----|------|------|--------|--------|
| showRefresh | 是否显示刷新按钮 | boolean | — | true |
| showDensity | 是否显示密度切换 | boolean | — | true |

## 五、BasePageFooter 页面底部操作栏

**功能说明**：承载页面底部操作区，支持默认取消/确认按钮和自定义操作区，支持 static/fixed 两种布局模式。

### 基础用法

```vue
<template>
  <div style="height: 600px; padding: 24px; background: #FAFAFA;">
    <div style="padding: 20px; border: 1px solid #EBEEF5; background: #fff;">
      <!-- 表单/详情内容 -->
    </div>
    <el-page-form-footer
      @cancel="handleCancel"
      @confirm="handleConfirm"
    />
  </div>
</template>

<script>
export default {
  methods: {
    handleCancel() {
      this.$message.info('点击了取消');
    },
    handleConfirm() {
      this.$message.success('点击了确认');
    }
  }
}
</script>
```

### 固定模式

```vue
<el-page-form-footer
  anchor=".app-main"
  mode="fixed"
/>
```

- `mode="fixed"` 时，组件根据锚点容器实时同步 `left` 和 `width`
- `anchor` 支持 HTMLElement、组件实例或选择器字符串
- `full=false` 时不再强制同步宽度，适合只需定位不撑满容器的场景

### 自定义操作区

```vue
<el-page-form-footer :loading="loading" :disabled="disabled">
  <template slot-scope="scope">
    <el-button :disabled="scope.disabled" @click="scope.cancel">返回列表</el-button>
    <el-button type="primary" :loading="scope.loading" :disabled="scope.disabled" @click="scope.confirm">
      提交审批
    </el-button>
  </template>
</el-page-form-footer>
```

### Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| --- | --- | --- | --- | --- |
| show-cancel | 是否显示取消按钮 | boolean | — | true |
| show-confirm | 是否显示确认按钮 | boolean | — | true |
| cancel-text | 取消按钮文案 | string | — | 取消 |
| confirm-text | 确认按钮文案 | string | — | 确认 |
| confirm-type | 确认按钮类型 | string | primary/success/warning/danger | primary |

## 九、BaseProProcess 流程查看

**功能说明**：展示流程节点状态、待办人员、操作记录、审批意见，支持分支切换、催办、自动拉取流程日志。

### 基础用法

```vue

  title="审批流程"
  :default-data="processList"
  :show-urge-button="true"
  @branch-change="handleBranchChange"

```

### 节点状态说明

| 状态值 | 含义 | 显示效果 |
|--------|------|----------|
| `completed` | 已完成 | 通过图标 |
| `running` | 进行中 | 待处理图标，可催办 |
| `rejected` | 退回/驳回 | 退回图标，连线高亮 |
| `notReached` | 未到达 | 空心圆 |
| `''` / 其他 | 兜底 | 按普通节点处理 |

### 展示规则

1. `running`、`notReached` 节点优先展示 `assignees`，其他状态优先展示 `handleUserName` + `handlePostName`
2. `running` 且 `assignees` 多人时合并展示，但不展示操作记录区
3. 普通节点/网关节点只要带有可见分支，就允许展开
4. `branches` 只有一条时，不显示分支切换按钮，直接展开
5. 存在 `running` 节点时：会隐藏该节点之前/之外的 `notReached` 节点，但保留真实执行链上位于 `running` 之前的 `completed / rejected` 节点
6. 若 `running` 位于网关内部，则只保留真实执行分支上的已执行祖先节点
7. 当全部节点都已 `completed` 时，不展示纯 `notReached` 节点
8. 操作记录区按 `actions[].group` 分组显示；未返回 `group` 时按单组处理
9. 每组只显示该组最后一个非空 `opinion`，显示在该组记录末尾

## 十、BaseProcessHandle 流程处理页

**功能说明**：搭建标准三栏流程处理页面（左：流程日志、中：业务内容、右：审批表单）。

> **待办跳转说明**：待办路径示例 `/message-web/test?taskId=[taskId]&businessCode=[businessCode]&instId=[instId]`。详情路径配置 `type=detail` 会自动隐藏底部按钮栏并设置右侧表单禁用状态。提交成功后调用 `window.$eventBus.emit('todo:refresh')` 刷新待办数量。是否"我的待办"通过待办的 `accountId` 与缓存的 `mainAccountId` 对比判断。

## 十二、常见问题

### 1. BaseProTable 不显示数据？

检查：
- 是否正确配置了 `request` 函数
- `request` 函数是否返回 `{ data: [], total: 0, success: true }` 格式
- 是否设置了 `:data` 属性（与 `request` 二选一）

### 2. BaseProForm 提交数据不正确？

检查：
- 是否正确设置了 `:initial-values`（编辑模式）
- 字段的 `dataIndex` 是否与数据字段名一致
- 是否正确配置了 `form.type`

### 3. BaseDictionary 不显示选项？

检查：
- 是否正确配置了 `appCode` 和 `distTypeCode`
- 字典数据是否已配置
- 网络请求是否正常

### 4. 文件上传失败？

检查：
- 是否正确配置了 `action` 地址
- 是否设置了 `autoUpload` 或手动调用上传
- 文件大小是否超过 `maxFileSize` 限制
- 文件类型是否符合 `accept` 要求

## 十三、MicroKeepAliveView 微前端页签保活

**功能说明**：用于 `qiankun + Vue 2 + 多页签` 场景，在子应用内部替代普通 `router-view`，根据「微应用名 + 主应用页签 ID + 子应用路由」生成缓存 key，并在主应用关闭页签或业务主动清理时删除子应用内部 vnode 缓存。

解决「主应用保活了微应用壳组件，但子应用还需要按页签精确保活页面」的问题。

### 基础用法

在子应用根组件中用 `MicroKeepAliveView` 替换 `router-view`，并在 qiankun 入口创建 runtime：

```html
<!-- App.vue -->
<template>
  <div id="app">
    <MicroKeepAliveView v-if="isQiankunRuntime" />
    <router-view v-else />
  </div>
</template>

<script>
import ElementUI from '@custom/element-ui';
const { MicroKeepAliveView } = ElementUI;
export default {
  components: { MicroKeepAliveView },
  computed: {
    isQiankunRuntime() { return window.__POWERED_BY_QIANKUN__ === true; }
  }
};
</script>
```

```js
// main.js - mount 中创建 runtime
import { MicroKeepAliveView } from '@custom/element-ui';
const { createMicroKeepAliveRuntime } = MicroKeepAliveView;

export async function mount(props = {}) {
  const runtime = createMicroKeepAliveRuntime({
    ...props,
    appName: 'newUpmsWeb',
    basename: '/new-upms-web',
    eventBus: props.eventBus || window.$eventBus,
    keepAliveMax: 20
  });
  runtime.bindRouterRestore(router);
  runtime.onResume();
  runtime.onPause();
  runtime.onDropCache();
  // provide runtime 给 MicroKeepAliveView
}
```

### 缓存 Key 格式

完整缓存 key 格式：`appName::tabId::routeKey`

| 清理粒度 | dropKeys 示例 | 说明 |
| --- | --- | --- |
| 精确页面 | `['newUpmsWeb::tab-1::/role']` | 只清理某个页签中的某个路由页面 |
| 整个页签 | `['newUpmsWeb::tab-1::']` | 清理某个页签下的全部页面缓存 |
| 整个子应用 | `['newUpmsWeb::']` | 清理某个子应用下的全部页签缓存 |

### 路由级缓存配置

```js
export const routes = [
  {
    path: '/role',
    component: () => import('@/views/role/index.vue'),
    meta: { keepAlive: true }       // 最小写法
  },
  {
    path: '/detail/:id',
    component: () => import('@/views/detail/index.vue'),
    meta: {
      keepAlie: true,
      cacheKey(route) { return `/detail/${route.params.id}`; }  // 按 ID 拆分缓存
    }
  },
  {
    path: '/submit',
    meta: { noCache: true }        // 明确不缓存
  }
];
```

### 页面级动态缓存策略

在页面组件上声明 `microKeepAlive` 自定义选项：

```js
export default {
  name: 'DemoDetail',
  microKeepAlive: {
    shouldCache(route, context) {
      return route.query.cache !== 'false' && Boolean(route.query.id || context.activeTab);
    },
    cacheKey(route) {
      return `/detail/${route.query.id || 'new'}`;
    },
    beforeDropCache({ route, cacheKey, payload }) {
      // 缓存清理前执行，适合停止轮询、保存草稿
    }
  }
};
```

`microKeepAlive` 支持字段：

| 字段 | 说明 |
| --- | --- |
| `shouldCache(route, context)` | 返回 `true` 时当前路由才进入缓存 |
| `cacheKey(route, context)` | 返回页面级 `routeKey`，runtime 自动拼接 `appName::tabId::` |
| `beforeDropCache(context)` | 缓存删除前回调，可清理页面副作用 |

### 页面生命周期

被缓存后，Vue 2 原生的 `activated` / `deactivated` 正常触发：

- `mounted` → 只需要初始化一次的逻辑
- `activated` → 每次从缓存恢复时触发，适合恢复轮询、刷新数据
- `deactivated` → 页面离开当前视图但仍保留缓存时触发，适合暂停轮询
- `beforeDestroy` → 缓存被真正删除时触发，用于最终清理

### 常用 runtime 参数

| 参数 | 说明 |
| --- | --- |
| `appName` | 当前子应用名称，必须和主应用事件中的 `appName` 一致 |
| `eventBus` | 主子应用共享事件总线，需支持 `on` 和 `emit` |
| `basename` | 子应用在主应用中的路径前缀 |
| `keepAliveMax` | 子应用内部 `keep-alive` 的最大缓存数量 |
| `getActiveTab` | 返回主应用当前激活页签 |
| `getTabs` | 返回主应用页签列表 |

### 注意事项

- `MicroKeepAliveView` 不直接管理主应用页签数组，主应用需发送 `app:resume`、`app:pause`、`app:drop-cache` 等事件
- 子应用缓存 key 一定包含 `appName` 和 `tabId`，用于隔离同一路由在不同页签下的页面实例
- 如子应用完全不需要页面缓存，可以不接入 `MicroKeepAliveView`
- 关闭当前正在渲染的页面时，缓存删除可能会延迟到路由切换后执行
