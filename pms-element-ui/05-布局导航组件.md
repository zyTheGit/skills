# 布局导航组件

> 10个布局导航组件，用于构建页面结构和导航

---

## 组件列表

| 组件 | 说明 | 常用场景 |
|-----|------|---------|
| Layout | 布局 | 页面整体布局 |
| Container | 布局容器 | 布局组合容器 |
| Breadcrumb | 面包屑 | 路径导航 |
| Dropdown | 下拉菜单 | 下拉菜单导航 |
| Menu | 菜单 | 导航菜单 |
| Tabs | 标签页 | 选项卡切换 |
| Steps | 步骤条 | 步骤导航 |
| PageHeader | 页头 | 页面头部 |
| Divider | 分割线 | 内容分隔 |
| Backtop | 回到顶部 | 页面滚动返回 |

## 三、Tabs 标签页

### 基础用法

```vue
<el-tabs v-model="activeName" @tab-click="handleClick">
  <el-tab-pane label="用户管理" name="first">用户管理</el-tab-pane>
  <el-tab-pane label="配置管理" name="second">配置管理</el-tab-pane>
  <el-tab-pane label="角色管理" name="third">角色管理</el-tab-pane>
</el-tabs>
```

### 无下划线

使用 `lineless` 属性隐藏下划线：

```vue
<el-tabs v-model="activeName" lineless>
  <el-tab-pane label="用户管理" name="first">用户管理</el-tab-pane>
  <el-tab-pane label="配置管理" name="second">配置管理</el-tab-pane>
</el-tabs>
```

### 卡片样式

```vue
<el-tabs v-model="activeName" type="card" closable @tab-remove="removeTab">
  <el-tab-pane label="用户管理" name="first">用户管理</el-tab-pane>
  <el-tab-pane label="配置管理" name="second">配置管理</el-tab-pane>
</el-tabs>
```

### 尺寸设置

使用 `size` 属性设置标签页尺寸，支持 `large` 和 `xlarge`：

```vue
<!-- 默认尺寸 -->
<el-tabs v-model="activeName">
  <el-tab-pane label="用户管理" name="first">用户管理</el-tab-pane>
</el-tabs>

<!-- 大尺寸 -->
<el-tabs v-model="activeName" size="large">
  <el-tab-pane label="用户管理" name="first">用户管理</el-tab-pane>
</el-tabs>

<!-- 超大尺寸 -->
<el-tabs v-model="activeName" size="xlarge">
  <el-tab-pane label="用户管理" name="first">用户管理</el-tab-pane>
</el-tabs>
```

### 动态增减标签页

```vue
<el-tabs v-model="editableTabsValue" type="card" editable @edit="handleTabsEdit">
  <el-tab-pane
    :key="item.name"
    v-for="item in editableTabs"
    :label="item.title"
    :name="item.name"
  >
    {{ item.content }}
  </el-tab-pane>
</el-tabs>
```

### Tabs Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
|-----|------|------|--------|--------|
| value / v-model | 绑定值，选中选项卡的 name | string | — | 第一个选项卡的 name |
| type | 风格类型 | string | card / border-card | — |
| closable | 标签是否可关闭 | boolean | — | false |
| lineless | 隐藏下划线 | boolean | — | false |
| addable | 标签是否可增加 | boolean | — | false |
| editable | 标签是否同时可增加和关闭 | boolean | — | false |
| tab-position | 选项卡所在位置 | string | top / right / bottom / left | top |
| stretch | 标签的宽度是否自撑开 | boolean | — | false |
| size | 标签页尺寸 | string | large / xlarge | — |
| before-leave | 切换标签之前的钩子 | Function(activeName, oldActiveName) | — | — |

```vue

  <el-breadcrumb-item>活动管理</el-breadcrumb-item>
```

## 十、Container 布局容器

**功能说明**：用于快速搭建页面基本结构的布局容器组件，基于 flex 布局。

### 基础用法

```vue
<el-container>
  <el-header>Header</el-header>
  <el-container>
    <el-aside width="200px">Aside</el-aside>
    <el-main>Main</el-main>
  </el-container>
</el-container>
```

### 常用属性

| 组件 | 参数 | 说明 | 类型 | 默认值 |
|------|------|------|------|--------|
| el-container | direction | 排列方向。有 header/footer 时自动为 vertical，否则 horizontal | horizontal / vertical | auto |
| el-header | height | 头部高度 | string | 60px |
| el-aside | width | 侧边栏宽度 | string | 300px |
| el-footer | height | 底部高度 | string | 60px |

### 注意事项

- 采用 flex 布局
- `el-container` 的子元素只能是 `el-header`、`el-aside`、`el-main`、`el-footer`
- 这些子元素的父元素必须是 `el-container`
