# 反馈组件

> 11个反馈组件，用于用户操作反馈和提示

---

## 组件列表

| 组件 | 说明 | 常用场景 |
|-----|------|---------|
| Alert | 警告 | 警告提示 |
| Dialog | 对话框 | 模态对话框 |
| Drawer | 抽屉 | 侧边抽屉 |
| Loading | 加载 | 加载状态 |
| Message | 消息提示 | 全局消息 |
| MessageBox | 消息弹框 | 确认对话框 |
| Notification | 通知 | 通知提醒 |
| Popover | 气泡弹出框 | 气泡卡片 |
| Popconfirm | 气泡确认框 | 气泡确认 |
| Tooltip | 文字提示 | 悬浮提示 |

## 一、Dialog 对话框

### 基础用法

```vue
<el-button type="text" @click="dialogVisible = true">点击打开 Dialog</el-button>

<el-dialog
  title="提示"
  :visible.sync="dialogVisible"
  width="30%"
  :before-close="handleClose">
  <span>这是一段信息</span>
  <span slot="footer" class="dialog-footer">
    <el-button @click="dialogVisible = false">取 消</el-button>
    <el-button type="primary" @click="dialogVisible = false">确 定</el-button>
  </span>
</el-dialog>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| visible | 是否显示 | boolean | false |
| title | 标题 | string | - |
| width | 宽度 | string | 50% |
| fullscreen | 是否全屏 | boolean | false |
| modal | 是否显示遮罩层 | boolean | true |
| close-on-click-modal | 点击遮罩关闭 | boolean | true |
| before-close | 关闭前的回调 | function | - |

### 自定义内容

```vue
<el-dialog :visible.sync="dialogVisible">
  <el-form :model="form">
    <el-form-item label="活动名称">
      <el-input v-model="form.name"></el-input>
    </el-form-item>
  </el-form>
  <span slot="footer">
    <el-button @click="dialogVisible = false">取消</el-button>
    <el-button type="primary" @click="handleConfirm">确定</el-button>
  </span>
</el-dialog>
```

## 二、Message 消息提示

### 基础用法

```javascript
// 成功消息
this.$message.success('成功');

// 警告消息
this.$message.warning('警告');

// 错误消息
this.$message.error('错误');

// 普通消息
this.$message('这是一条消息提示');

// 可关闭的消息
this.$message({
  message: '恭喜你，这是一条成功消息',
  type: 'success',
  showClose: true
});
```

### 配置项

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| message | 消息文字 | string / VNode | - |
| type | 主题 | string | info |
| duration | 显示时间(ms) | number | 3000 |
| showClose | 显示关闭按钮 | boolean | false |
| center | 文字居中 | boolean | false |

## 三、MessageBox 消息弹框

### 基础用法

```javascript
// 警告框
this.$alert('消息内容', '标题', {
  confirmButtonText: '确定',
  callback: action => {
    this.$message({
      type: 'info',
      message: `action: ${action}`
    });
  }
});

// 确认框
this.$confirm('此操作将永久删除该文件, 是否继续?', '提示', {
  confirmButtonText: '确定',
  cancelButtonText: '取消',
  type: 'warning'
}).then(() => {
  this.$message.success('删除成功!');
}).catch(() => {
  this.$message.info('已取消删除');
});

// 提示框
this.$prompt('请输入邮箱', '提示', {
  confirmButtonText: '确定',
  cancelButtonText: '取消',
  inputPattern: /[\w!#$%&'*+/=?^_`{|}~-]+(?:\.[\w!#$%&'*+/=?^_`{|}~-]+)*@(?:[\w](?:[\w-]*[\w])?\.)+[\w](?:[\w-]*[\w])?/,
  inputErrorMessage: '邮箱格式不正确'
}).then(({ value }) => {
  this.$message.success('你的邮箱是: ' + value);
});
```

## 六、Loading 加载

加载数据时显示动效。

### 指令方式

```vue
<el-table v-loading="loading" element-loading-type="image" :data="tableData">
  <!-- 表格内容 -->
</el-table>
```

### 自定义文案和样式

```vue
<el-table
  v-loading="loading"
  element-loading-text="拼命加载中"
  element-loading-spinner="el-icon-loading"
  element-loading-background="rgba(0, 0, 0, 0.8)"
  :data="tableData">
</el-table>
```

### 整页加载

```vue
<el-button
  type="primary"
  @click="openFullScreen1"
  v-loading.fullscreen.lock="fullscreenLoading"
  element-loading-type="image">
  指令方式
</el-button>

<el-button type="primary" @click="openFullScreen2">服务方式</el-button>

<script>
export default {
  data() {
    return {
      fullscreenLoading: false
    }
  },
  methods: {
    openFullScreen1() {
      this.fullscreenLoading = true;
      setTimeout(() => { this.fullscreenLoading = false; }, 2000);
    },
    openFullScreen2() {
      const loading = this.$loading({ lock: true, type: 'image' });
      setTimeout(() => { loading.close(); }, 2000);
    }
  }
}
</script>
```

### 服务方式

```javascript
import { Loading } from 'element-ui';

const loading = Loading.service({
  lock: true,
  text: 'Loading',
  spinner: 'el-icon-loading',
  background: 'rgba(0, 0, 0, 0.7)'
});
this.$nextTick(() => {
  loading.close();
});
```

> 全屏 Loading 是单例的，多次调用返回同一实例。

### Options

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
|------|------|------|--------|--------|
| target | Loading 覆盖的 DOM 节点 | object/string | — | document.body |
| body | 插入至 body | boolean | — | false |
| fullscreen | 全屏遮罩 | boolean | — | true |
| lock | 锁定屏幕滚动 | boolean | — | false |
| text | 加载文案 | string | — | — |
| spinner | 自定义加载图标类名 | string | — | — |
| background | 遮罩背景色 | string | — | — |
| customClass | 自定义类名 | string | — | — |
| type | 加载类型（如 image） | string | — | — |

## 十、常用组合示例

### 删除确认

```vue
<template>
  <el-popconfirm
    title="确定删除吗？"
    @confirm="handleDelete">
    <el-button
      slot="reference"
      type="danger"
      size="small"
      :loading="deleting">
      删除
    </el-button>
  </el-popconfirm>
</template>

<script>
export default {
  data() {
    return {
      deleting: false
    };
  },
  methods: {
    async handleDelete() {
      this.deleting = true;
      try {
        await this.deleteItem();
        this.$message.success('删除成功');
      } catch (error) {
        this.$message.error('删除失败');
      } finally {
        this.deleting = false;
      }
    }
  }
};
</script>
```

### 操作反馈

```javascript
// 提交成功
try {
  await this.submitForm();
  this.$message.success('提交成功');
  this.dialogVisible = false;
} catch (error) {
  this.$message.error('提交失败：' + error.message);
}

// 删除确认
this.$confirm('此操作将永久删除该文件, 是否继续?', '提示', {
  type: 'warning'
}).then(async () => {
  await this.deleteFile();
  this.$message.success('删除成功');
  this.loadData();
}).catch(() => {
  // 取消操作
});
```

## 十一、Tooltip 文字提示

**功能说明**：鼠标悬停时显示文本提示，常用于展示上下文信息。

### 基础用法

```vue
<el-tooltip effect="dark" content="顶部提示" placement="top">
  <el-button>悬停查看</el-button>
</el-tooltip>
```

### 常用属性

| 参数 | 说明 | 类型 | 默认值 |
|-----|------|------|--------|
| effect | 主题 | dark / light | dark |
| content | 提示文本（或使用 `slot="content"`） | string | — |
| placement | 引出位置 | top / top-start / top-end / bottom / bottom-start / bottom-end / left / left-start / left-end / right / right-start / right-end | bottom |
| value / v-model | 是否显示 | boolean | false |
| disabled | 是否禁用 | boolean | false |
| offset | 出现位置的偏移量 | number | 0 |
| transition | 定义渐变动画 | string | el-fade-in-linear |
| visible-arrow | 是否显示箭头 | boolean | true |
| open-delay | 出现前的延迟（ms） | number | 0 |
| manual | 手动控制模式 | boolean | false |
| enterable | 鼠标是否可进入 tooltip | boolean | true |
| hide-after | 自动隐藏延迟（ms），0 为不自动隐藏 | number | 0 |
| popper-class | 为 popper 添加类名 | string | — |
| tabindex | tabindex 属性 | number | 0 |

### 注意事项

- tooltip 内容不支持 `router-link`，请使用 `vm.$router.push` 替代
- 禁用的表单元素内部不会触发 mouseenter，需在外层包裹一个容器元素
