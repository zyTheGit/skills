# 快速开始

> 安装指南、快速上手、全局SDK使用说明

---

## 一、安装与配置

### npm 安装

```bash
npm i element-ui -S
```

### CDN 引入

```html
<!-- 引入样式 -->
<link rel="stylesheet" href="https://unpkg.com/element-ui/lib/theme-chalk/index.css">
<!-- 引入组件库 -->
<script src="https://unpkg.com/element-ui/lib/index.js"></script>
```

### 完整引入

```javascript
import Vue from 'vue';
import ElementUI from 'element-ui';
import 'element-ui/lib/theme-chalk/index.css';
import App from './App.vue';

Vue.use(ElementUI);

new Vue({
  el: '#app',
  render: h => h(App)
});
```

### 按需引入

```bash
npm install babel-plugin-component -D
```

配置 `.babelrc`：

```json
{
  "presets": [["es2015", { "modules": false }]],
  "plugins": [
    [
      "component",
      {
        "libraryName": "element-ui",
        "styleLibraryName": "theme-chalk"
      }
    ]
  ]
}
```

### 全局配置

```javascript
import Vue from 'vue';
import Element from 'element-ui';
Vue.use(Element, { size: 'small', zIndex: 3000 });
```

## 二、Min-Web3 全局 SDK

> 基于 qiankun 微前端架构的全局 SDK，包含通信、权限、工具、历史管理、性能监控、错误处理等模块

### 快速开始

所有全局 SDK 在主应用启动时自动挂载到 `window` 对象，子应用可直接使用：

```javascript
// 子应用中直接使用
if (window.__POWERED_BY_QIANKUN__) {
  // 打开新标签页
  window.$utils.openTab({
    appName: 'app-user',
    name: 'user-detail-123',
    path: '/app-user/detail/123',
    title: '用户详情'
  });
  
  // 检查权限
  if (window.$permission.check('user:edit')) {
    // 有编辑权限
  }
  
  // 通过 mainStore 获取主应用数据（响应式）
  const userInfo = this.$mainStore.state.user.userInfo;
  
  // 发送消息给主应用
  window.$eventBus.emit('message:fromApp', {
    appName: 'app-user',
    type: 'USER_UPDATED',
    data: { id: 123 }
  });
}
```

### window.$utils - 工具 SDK

提供标签页管理、日期格式化、本地存储、防抖节流等通用工具。

#### 标签页管理

**openTab(tab) - 打开新标签页**

```javascript
window.$utils.openTab({
  appName: 'app-user',
  name: 'user-detail-123',
  path: '/app-user/detail/123',
  title: '用户详情',
  keepAlive: true  // 切换标签时保留组件状态
});
```

**closeCurrentTab() - 关闭当前标签页**

```javascript
await window.$utils.closeCurrentTab();
```

**closeCurrentAndOpenTab(tab) - 关闭当前并打开新标签页**

```javascript
await window.$utils.closeCurrentAndOpenTab({
  appName: 'app-user',
  name: 'user-list',
  path: '/app-user/list',
  title: '用户列表'
});
```

**updateTabSubRoute(tabName, subRoute) - 更新标签页子路由**

```javascript
// 子应用路由守卫中调用
router.afterEach((to) => {
  if (window.__POWERED_BY_QIANKUN__ && window.$utils) {
    const tabName = 'user-list';
    window.$utils.updateTabSubRoute(tabName, to.fullPath);
  }
});
```

**getActiveTab() / getAllTabs()**

```javascript
const activeTab = window.$utils.getActiveTab();
const tabs = window.$utils.getAllTabs();
```

#### 日期工具

**formatDate(date, format)**

```javascript
window.$utils.formatDate(new Date()); // '2024-01-15 10:30:00'
window.$utils.formatDate(new Date(), 'YYYY-MM-DD'); // '2024-01-15'
```

**getRelativeTime(date) - 相对时间**

```javascript
window.$utils.getRelativeTime(Date.now() - 30000);   // '刚刚'
window.$utils.getRelativeTime(Date.now() - 60000);   // '1分钟前'
window.$utils.getRelativeTime(Date.now() - 3600000); // '1小时前'
```

#### 本地存储

```javascript
// 永久存储
window.$utils.storage.set('user', { name: '张三', age: 25 });

// 带过期时间（1小时）
window.$utils.storage.set('token', 'xxx-token', 3600000);

// 读取
const user = window.$utils.storage.get('user');

// 带默认值
const count = window.$utils.storage.get('count', 0);

// 删除
window.$utils.storage.remove('user');
window.$utils.storage.clear();

// 检查
if (window.$utils.storage.has('token')) {
  // token 存在且未过期
}
```

#### 函数工具

**debounce(fn, delay) - 防抖**

```javascript
const debouncedSearch = window.$utils.debounce((keyword) => {
  api.search(keyword);
}, 500);
```

**throttle(fn, delay) - 节流**

```javascript
const throttledScroll = window.$utils.throttle(() => {
  console.log('滚动位置:', window.scrollY);
}, 200);
```

#### 对象工具

**deepClone(obj) - 深拷贝**

```javascript
const copy = window.$utils.deepClone(original);
```

**isEmpty(value) - 判断空值**

```javascript
window.$utils.isEmpty(null);       // true
window.$utils.isEmpty('');         // true
window.$utils.isEmpty([]);         // true
window.$utils.isEmpty({});         // true
```

#### URL 工具

**parseQuery(url) / buildQuery(params)**

```javascript
const params = window.$utils.parseQuery('/page?id=123&name=test');
// { id: '123', name: 'test' }

const query = window.$utils.buildQuery({ id: 123, name: '张三' });
// 'id=123&name=%E5%BC%A0%E4%B8%89'
```

### window.$request - 请求方法

二次封装 `axios`，支持请求级别配置覆盖、加密加签、取消请求。

> **注意**：子应用使用 external 配置：`externals: process.env.NODE_ENV === 'production' ? {'@custom/pms-request': '$request'} : null`

#### 基础配置

```javascript
import { setupRequest, get, post } from '@custom/pms-request'

// 初始化配置（子应用不需要初始化）
setupRequest({
  baseURL: '/api',
  getToken: () => localStorage.getItem('token'),
  onAuthError: () => router.push('/login'),
  onError: (msg) => Message.error(msg),
})

// 发起请求
const users = await get({ url: '/users', params: { page: 1 } })
const result = await post({ url: '/users', data: { name: 'test' } })
```

#### 配置项

**基础配置**

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| baseURL | string | '' | API 基础地址 |
| timeout | number | 10000 | 超时时间（毫秒） |
| withCredentials | boolean | true | 是否携带 cookie |
| headers | object | { 'Content-Type': 'application/json' } | 默认请求头 |

**Token 配置**

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| getToken | () => string | null | 获取 token 函数 |
| tokenHeaderName | string | 'Authorization' | token 请求头名称 |
| tokenPrefix | string | 'Bearer ' | token 前缀 |

**错误处理配置**

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| authErrorCodes | number[] | [40101, 401] | 登录失效错误码 |
| onAuthError | (res) => void | null | 登录失效回调 |
| onError | (msg) => void | null | 错误提示回调 |
| onLoadingStart | () => void | null | Loading 开始回调 |
| onLoadingEnd | () => void | null | Loading 结束回调 |

#### 加密示例

```javascript
// 登录接口 - password 字段会被自动加密
await post({
  url: '/login',
  data: {
    username: 'admin',
    password: '123456',  // 会被加密
  },
  crypto: {
    sm4: {
      fields: ['password']
    }
  }
})
```

#### 取消请求

```javascript
import { get, cancelRequest, cancelAllRequests } from 'pms-base-request'

// 发起可取消的请求
get({ url: '/search', params: { q: 'test' }, cancelKey: 'search' })

// 取消指定请求
cancelRequest('search')

// 取消所有请求
cancelAllRequests()
```

### window.$eventBus - 事件总线

轻量级事件总线，用于主应用与子应用之间的事件通信。

> **注意**：状态数据（如 userInfo、token）应通过 `this.$mainStore` 响应式获取，eventBus 仅用于事件通知。

**on(event, callback, options) - 订阅事件**

```javascript
const unsubscribe = window.$eventBus.on('route:restore', (payload) => {
  console.log('收到路由恢复请求', payload);
}, { appName: 'app-user' });

// 在组件销毁时取消订阅
beforeDestroy() {
  unsubscribe();
}
```

**once(event, callback, options) - 订阅一次**

```javascript
window.$eventBus.once('app:ready', (data) => {
  console.log('应用就绪', data);
});
```

**emit(event, data, options) - 发布事件**

```javascript
window.$eventBus.emit('message:fromApp', {
  appName: 'app-user',
  type: 'USER_UPDATED',
  data: { id: 123, name: '张三' }
});
```

**off(event, callback) - 取消订阅**

```javascript
window.$eventBus.off('route:restore', myCallback);
```

**预定义事件**

| 事件名 | 方向 | 说明 |
|--------|------|------|
| `route:restore` | 主应用 → 子应用 | 通知子应用恢复路由 |
| `route:update` | 子应用 → 主应用 | 子应用通知主应用更新 subRoute |
| `message:fromApp` | 子应用 → 主应用 | 子应用发送消息给主应用 |

### 子应用获取主应用数据

子应用通过 `this.$mainStore` 响应式获取主应用的 Vuex 状态。

**在子应用中访问主应用 Store**

```javascript
// 子应用 main.js 中
export async function mount(props) {
  Vue.prototype.$mainStore = props.mainStore;
  Vue.prototype.$mainRouter = props.mainRouter;
}
```

**获取用户信息**

```javascript
export default {
  computed: {
    userInfo() {
      return this.$mainStore?.state?.user?.userInfo;
    },
    token() {
      return this.$mainStore?.state?.user?.token;
    },
    permissions() {
      return this.$mainStore?.state?.permission?.permissions || [];
    },
    activeTab() {
      return this.$mainStore?.state?.tabs?.activeTab;
    }
  }
}
```

**可用的 Store 模块**

| 模块 | 路径 | 说明 |
|------|------|------|
| user | `state.user.userInfo` | 用户信息 |
| user | `state.user.token` | 登录 token |
| permission | `state.permission.permissions` | 权限列表 |
| tabs | `state.tabs.tabs` | 所有标签页 |
| tabs | `state.tabs.activeTab` | 当前激活标签页 |

### window.$permission - 权限 SDK

统一的权限校验工具，支持按钮级权限控制。

**check(permission) - 检查单个权限**

```javascript
if (window.$permission.check('user:add')) {
  // 显示添加按钮
}
```

**checkAny(permissions) - 检查任一权限**

```javascript
if (window.$permission.checkAny(['user:add', 'user:edit'])) {
  // 显示操作按钮
}
```

**checkAll(permissions) - 检查所有权限**

```javascript
if (window.$permission.checkAll(['user:view', 'user:edit', 'user:delete'])) {
  // 显示高级管理功能
}
```

**在 Vue 组件中使用**

```vue
<template>
  <el-button v-if="hasAddPermission" @click="handleAdd">新增</el-button>
</template>

<script>
export default {
  computed: {
    hasAddPermission() {
      return window.$permission?.check('user:add') ?? false;
    }
  }
}
</script>
```

**权限指令**

```vue
<el-button v-permission="'user:add'">新增</el-button>
```

**权限码命名规范**

```javascript
'user:view'    // 查看用户
'user:add'     // 新增用户
'user:edit'    // 编辑用户
'user:delete'  // 删除用户
'order:export' // 导出订单
```

### 表单校验工具

`window.$utils.validators` 提供统一的表单校验逻辑：

**校验手机号**

```javascript
window.$utils.validators.validatePhone('13800138000');   // true
```

**校验身份证号**

```javascript
window.$utils.validators.validateIdCard('11010519491231002X');
```

**校验邮箱**

```javascript
window.$utils.validators.validateEmail('demo@example.com'); // true
```

**校验密码强度**

```javascript
const result = window.$utils.validators.validatePasswordStrength('Abc123!@#xyz');
// {
//   valid: false,
//   rules: {
//     length: true,
//     complexity: true,
//     noSequence: false
//   }
// }
```

校验规则：
- 长度需为 **10-20 位**
- 必须同时包含 **大写字母 / 小写字母 / 数字 / 特殊字符**
- 不能包含常见简单序列（如 `123`、`abc`、`qwerty`、`password` 等）

### 最佳实践

**1. 安全访问全局对象**

```javascript
// 推荐：使用可选链
window.$utils?.openTab(tab);
window.$permission?.check('user:add');

// 或者先检查环境
if (window.__POWERED_BY_QIANKUN__ && window.$utils) {
  window.$utils.openTab(tab);
}
```

**2. 标签页命名规范**

```javascript
// 推荐：使用 业务名-唯一标识 格式
const tabName = `user-detail-${userId}`;
const tabName = `order-edit-${orderId}`;

// 列表页可以使用固定名称
const tabName = 'user-list';
```

**3. 事件类型命名规范**

```javascript
// 推荐：使用 模块:动作 格式
'route:restore'     // 路由恢复
'route:update'      // 路由更新
'message:fromApp'   // 来自子应用的消息
```
